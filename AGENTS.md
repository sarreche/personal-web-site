# Project Guidelines

## Stack
- Next.js App Router
- TypeScript
- Tailwind CSS

## Principles
- Keep components small and reusable
- Prefer server components
- Avoid unnecessary dependencies
- Maintain visual consistency
- Mobile-first design
- Accessibility basics required

## Design Style
- Minimal
- Modern
- Soft pastel accents
- Clean spacing
- Premium but human

## Avoid
- Overengineering
- Heavy animation
- Complex abstractions
- Large UI libraries

## Folder Rules
/components -> reusable UI
/data -> editable content
/lib -> utilities
/app -> routes/layouts

## Coding Style
- Clear naming
- Semantic HTML
- Simple props
- Avoid deeply nested components
